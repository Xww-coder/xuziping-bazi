# 徐子平 · 八字人物卡牌

> 地球 Online 没有攻略，也不存在两个玩家共享同一张地图。
> 你出生那一刻，系统就发放了你的初始角色设定——天赋、热情、软肋、低谷，都写在里面。
> 这个项目只想做一件事：帮你把这张卡牌轻轻翻开。不是认命，是认得自己。

---

## 写在最前面：你的地图，只有你能点亮

你有没有过这样的时刻——

深夜刷着别人的朋友圈，忽然怀疑自己是不是选错了开局；看着别人的赛道里人来人往，而自己的地图上，还是一片没点亮的迷雾；明明很努力，却总觉得"我不该是这样的"。

我们太习惯拿别人的地图，来丈量自己的路。

但地球 Online 这款游戏，从第一天起就写得很明白：**每个人的出生时间，就是系统发放的初始角色设定**。有人开局是参天大树，有人开局是花草藤蔓；有人生在草原，天生适合奔跑；有人生在深海，天生适合沉潜。**没有谁的地图更高，只有适配与否。**

八字，就是你的角色设定卡。它不写结局，只写初始值：

- **天赋和热情**——是你地图上最亮的那几块区域。往那儿走，风是顺的，路是自己长出来的；
- **缺点和低谷期**——不是卡关，不是 bug，是这段剧情里必经的章节。承认它们，你才算真正把人生的控制权握回自己手里。

所以这个项目坚持不做两件事：**不给你贴输赢的标签，也不拿你和别人比**。

不用随波逐流，也不必对比焦虑。
找到适合自己的土壤和环境，静待花开。🌱

## 这是一张怎样的卡

把八字变成一张「**人类图**」。

每个人拿到手的不只是一份分析报告，而是一张**属于你自己的角色卡**——上面印着你的**命运剧本**和**天赋技能点**：

- **命运剧本**：你抽到的角色（如「田园织梦者」「破阵剑士」）、你这一生的主线任务（如「秩序与名望之路」「破旧立新之路」），以及你现在正走在剧情的第几章——低谷章节会被温柔地标出来，因为它不是卡关，是必经的剧情；
- **天赋与技能点**：你的本命技能（如「秩序光环」「破旧之刃」）、你的角色定位（正面作战 / 智谋协作 / 均衡发展），以及按喜用神给出的**加点建议**——喜用神不是"赢的配方"，而是告诉你天赋点该往哪儿投。

市面上太多工具只负责告诉你"你很棒"，而 `card.py` 生成的卡牌上，**「核心优势」和「性格弱点」是并排印着的**——就像塔罗牌的正位与逆位，都是这张牌的一部分。

每张卡牌包含两层：

- **视觉层**：3:4 竖版人物形象出图 Prompt。由「日主外貌 × 格局神态 × 身强身弱 × 五行配色」四层拼装而成，连背景的森林、江海、日光，都是按你的喜用神选定的；
- **文字层**：命运剧本、天赋技能点、核心优势、性格弱点、性格总评、当下心态。诚实，但不刻薄。

## 它为什么连「弱点」也写给你看

因为弱点不是要你改掉的 bug，而是你角色设定的一部分——是你这副牌的背面。**背面不丢人，被藏起来的背面才会长成内耗。**

同样的道理，也写在排盘的每个细节里：

- **身弱**不是"不行"，只是告诉你：你这套配置，更适合借力、协作、以柔取胜，而不是硬扛；
- **低谷期**（走忌神大运的年份）也不是判决，它只是在说：这段时间风不顺，适合慢一点、养一养、多借借贵人的力。低谷是用来渡过的，不是用来熬垮的；
- **喜用神**不是"赢的配方"，**忌神**也不是"该删掉的代码"。它们只说明：你在什么环境里舒展，在什么环境里消耗。知道了，你就可以主动选择土壤，而不是怪自己长不好。

命理给不了标准答案，但它能给你一张诚实的**地图**。剩下的路，是你自己走的。

## 它能做什么

| 能力 | 工具 | 说明 |
| --- | --- | --- |
| 🧭 精确排盘 | `paipan.py` | 四柱、藏干、五行分布、旺衰证据、格局候选、喜用神分层、大运流年 |
| 🎴 人物卡牌 | `card.py` | 把排盘结果拼装成 3:4 竖版卡牌：命运剧本 + 天赋技能点 + 形象 Prompt + 文字分析 |
| 🤖 AI 批命 | `SKILL.md` | 喂给 AI，以徐子平的口吻温厚解读事业、家庭、健康、流年 |

排盘引擎遵循传统命理的严谨规则：

- 年柱以**立春**分界，非正月初一；
- 月柱以**节气**分界，非农历月初；
- 时柱按**真太阳时**校正（出生地经度 + 均时差），海外与夏令时也可处理。

## 快速开始

```bash
pip install -r requirements.txt

# 排盘：输出四柱 / 五行 / 十神 / 格局 / 喜用神 / 大运
python3 paipan.py --date 1990-05-20 --time 14:30 --gender 男 --city 北京 --zwt 116.4 --tz-offset 8

# 人物卡牌：生成 3:4 竖版卡牌（命运剧本 + 天赋技能点 + 形象 Prompt + 文字分析）
python3 card.py --date 1990-05-20 --time 14:30 --gender 男 --city 北京 --zwt 116.4

# 输出 JSON，方便二次加工
python3 card.py --date 1990-05-20 --time 14:30 --gender 男 --json
```

### 参数说明

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `--date` | ✅ | 公历生日 `YYYY-MM-DD`（农历请先换算） |
| `--time` | ✅ | 出生时刻 `HH:MM`，越精确越好 |
| `--gender` | ✅ | `男` / `女`（决定大运顺逆） |
| `--city` | | 出生城市（用于真太阳时校正） |
| `--zwt` | | 出生地经度，东经为正（如北京 116.4） |
| `--tz-offset` | | 出生时当地 UTC 时差，默认 `8`（中国标准时间） |

### 你的卡牌长什么样

拿 1990-05-20 14:30 出生（北京）为例，卡牌的文字层会这样开场——

```
八字人物卡牌 · 乙木 · 正官格
角色：田园织梦者 ｜ 主线任务：「秩序与名望之路」

【命运剧本】
  角色定位：田园织梦者 —— 温柔坚韧、善于联结，天生的编织者，把散落的美好连成一片风景
  主线任务：「秩序与名望之路」—— 在规则之内，靠沉稳与担当，一步步建立自己的权威
  当前章节：第 4 章「并肩之战」—— 独立成长的一章，朋友与对手都会推着你往前走
  这一章是低谷章节（丙午年），风不顺，别硬刚——慢下来回血，低谷是用来渡过的

【天赋与技能点】
  本命技能：「秩序光环」（正官）—— 被信任与被托付的能力，稳重靠谱是你与生俱来的被动技能
  角色定位：智谋协作型 —— 血薄但敏捷点满，适合借力打力、以柔克刚，你的战场在幕后与细节
  加点建议：优先点亮「传承之心」与「慧眼识机」：多读书、多拜师，善用长辈与贵人的力
```

完整输出见 [`examples/`](examples/)，如 [`examples/card_sample_output.txt`](examples/card_sample_output.txt)。
